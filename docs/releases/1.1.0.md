# agent.mind 1.1.0

These notes describe the 1.1.0 release line. The
[GitHub release page](https://github.com/OnFiala/agent.mind/releases/tag/v1.1.0)
is authoritative for publication, final downloads and archive checksums; a source
version or these notes alone do not prove publication. Version 1.0.3 remains the
rollback release. Existing targets retain their pins until explicitly upgraded.
The [roadmap](../../ROADMAP.md) owns stage status. The merged
[preparation PR #6](https://github.com/OnFiala/agent.mind/pull/6) records the reviewed
implementation and upgrade checks. No private evidence is shipped.

## What changes from 1.0.3

- Source paging covers all lines and selected symbols refresh their source position
  after edits while preserving view state.
- Bounded inventory makes unsupported text visible and readable by current hash.
  Binary, oversized, excluded and unscanned files have explicit states. Conventional
  key/env paths are excluded before opening. Larger inventories can now make a
  formerly apparently complete scan partial.
- TS/TSX/JSX gains syntax-only named declarations, native kinds, parser provenance
  and UTF-16 ranges. Babel 7.29.12 was selected after a fixed-budget comparison;
  Acorn remains the JavaScript parser. Runtime dependencies stay inside the
  integration; no target compiler, install script, tsconfig or project code runs.

## Support boundary

This is a **typed-source inspection pilot**. Every typed file remains partial;
strict preflight still rejects it. No typed imports, type relationships, call graph,
JSX-component calls, security/HTTP or framework routing is inferred. Ambient `.d.ts`,
`.mts`/`.cts`, decorators and embedded scripts remain unsupported. Anonymous bodies,
class fields/static blocks and computed/string-named methods have explicit omissions.

The typed pre-parse cap is 64 KiB per file. Invalid syntax yields no recovery symbols;
ambiguous declarations and descendants are withheld. Traversal is bounded at 2,000
symbols, 100,000 AST nodes and depth 256. These are not parser deadlines or a sandbox.
Use the README for the full supported scope and bounded performance evidence.

Node >=22, macOS/Linux, loopback-only view and the existing project layout remain.
No Windows, remote-host or production editing acceptance is implied.

## Upgrade and recovery

Follow [Update from an older version](../../README.md#update-from-an-older-version).
There is no in-place or automatic updater. Retain the original 1.0.3 download and
save the user map outside the project; stop the view, uninstall with the old installed
CLI, verify the result, and park the preserved directory outside project inventory.
Install 1.1.0 from its verified bundle, restore the map, inspect status/context and
reload host instructions. Preserve edited/unknown files in the backup rather than
overwriting generated controls. A new installation has a new binding.

For rollback, use the same sequence with the original 1.0.3 release and saved map.
Post-uninstall recovery files are not an executable previous installation. Old
context/preflight receipts expire. Source inspection in 1.0.3 has its older limits.
No purge is part of upgrade/rollback. Caught-failure recovery does not establish
power-loss safety.

## Final documentation audit and bundle

The release documentation was checked against the current capability dispatch,
lifecycle responses, artifact allowlist and bundled licenses. Six bounded findings
were corrected: the comparison link missing from the runtime archive, the undated
artwork percentage, the missing Babel license summary, a stale test count, the
overbroad statement that all documentation is excluded, and an uninstall instruction
that referred to a nonexistent response field. Historical audit reports remain unchanged.
The README now separates source inventory, JavaScript relationships and syntax-only
typed inspection, and distinguishes the runtime archive from a development checkout.
The package description uses the same support boundary; the matching public
repository description is applied during release publication.

After these corrections, 165 local tests, nine actual-bundle smoke scenarios and
11 published-1.0.3 upgrade/rollback groups passed. Local links and heading anchors
were checked in both the repository README and the actual bundled README. The
release PR records independent review, hosted CI and any remaining process limits.
