## Upgrade and rollback

Use [Update from an older version](../../README.md#update-from-an-older-version).
Save the user map outside the project and retain the verified original release.
Stop the view, uninstall through the **currently installed CLI**, inspect successful
`state: "uninstalled"`, and park the preserved integration at a unique path outside
the project. Install the selected release into a fresh integration, restore the map,
inspect `status` and `context`, then reload the host's project instructions.
Preserve edited/unknown files and recovery copies; do not purge or overwrite them.

For rollback, repeat those steps using the original 1.2.0 archive:

- Source tag: `v1.2.0`, commit `38c5fa27b218e387b108b570b36d03f13498e83b`.
- Archive SHA-256: `8340c3f70801c3b09fe9c5f9a7a7b66d77008f7738c2b489e686a041d9b4f6c4`.
- Runtime digest: `6f27e1b1e1d8a0740847f7bfef1f06c04d8c73dbefe2719c71c746975537550d`.

Rollback retains the same language capabilities but restores the four known 1.2.0
limitations. Binding identity changes, so old context/preflight receipts expire.
Preserved post-uninstall directories are recovery data, not runnable installations.
If candidate verification fails after uninstall, reinstall the original verified
release and restore its map; never force installation over partial state.

The upgrade harness checks installed JS behavior through both versions and back,
Python partial/declarations and rejection by strict preflight, host source/package
and BOM/CRLF instructions, maps/aliases, edited/unknown files, parked recovery bytes,
active-view conflicts and tampered-candidate recovery. These are caught-failure
checks, not crash/power-loss atomicity or proof of automatic host instruction loading.

Each repair commit can be reverted independently in source; the release preparation
is a separate commit. A new corrective release should get a new version. Do not
retarget published tags or replace existing release archives. Withdrawing this
release from latest status does not downgrade already installed targets.
